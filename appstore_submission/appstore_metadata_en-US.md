## Description
Frame Photo Caption helps photographers and storytellers add elegant date and title text to photos in seconds.

Use your existing image folder, review extracted metadata, adjust text only when needed, and run batch export in one click. The app keeps your workflow simple and local.

Features:
- Batch process photos from a selected folder
- Automatically read capture date from EXIF metadata
- Read title from XMP sidecar or embedded XMP metadata
- Edit date/title per image before export
- Tune visual style with border, bottom spacing, padding, and font sizes
- Reset selected or all edits at any time
- Export high-quality framed images with progress and logs

Great for travel albums, wedding previews, portfolio curation, and personal archives.
